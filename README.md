# Tom Crossland

I build software whose claims can be checked: a backtest that counts every configuration it tried, a backup that verifies itself, a review whose every finding quotes its source. Most of my recent work is with Claude Code.

- **[github-curator](https://github.com/tcrossland/github-curator)**: a Claude plugin that recommends what to do with each repo on a GitHub account, on a scorecard whose quotes a script checks against their files.
- **[mailcellar](https://github.com/mailcellar/mailcellar)**: a checked, incremental backup of Gmail, Workspace and IMAP mail, which moves old mail out of the mailbox by rule and can put it back.
- **[stat-arb-from-scratch](https://github.com/tcrossland/stat-arb-from-scratch)**: does residual mean reversion in US equities survive real trading costs? So far, once every configuration tried is counted, no.
- **[claude-code-methodology](https://github.com/tcrossland/claude-code-methodology)**: a file-first way of working with Claude Code, where the discipline lives in files and enforced checks rather than in prompts.
- **[spacy-annotator](https://github.com/tcrossland/spacy-annotator)** (archived): a 2017 prototype for tagging entities in text beside a spaCy model that trains on them.
