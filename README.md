# Tom Crossland

I'm a software and data architect, and I now build tools and small research projects with Claude Code.

- [github-curator](https://github.com/tcrossland/github-curator), a Claude plugin that reviews the repos on a GitHub account and recommends what to do with each one
- [stat-arb-from-scratch](https://github.com/tcrossland/stat-arb-from-scratch), which tests whether a mean-reversion signal in US stocks survives trading costs (so far it doesn't)
- [Minnel](https://github.com/tcrossland/claude-code-methodology), a file-first way of working with Claude Code, with a plugin that installs its reviewer, guards and rituals
- [mailcellar](https://github.com/mailcellar/mailcellar), a local backup of Gmail and other mail that can move old mail out of the mailbox and back again
- [rust-quotient-filter](https://github.com/tcrossland/rust-quotient-filter), a 2016 quotient filter prototype in Rust for idempotent Kafka consumers
- [spacy-annotator](https://github.com/tcrossland/spacy-annotator), a 2017 web app for tagging named entities in text and training a spaCy model on them

I'm open to contract work and collaboration. To get in touch, [open an issue](https://github.com/tcrossland/tcrossland/issues/new) on this repo.
