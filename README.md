# Tom Crossland

Most of what I've published recently I built with Claude Code.

[github-curator](https://github.com/tcrossland/github-curator) is a Claude plugin that reviews the repos on a GitHub account and recommends what to do with each one. [mailcellar](https://github.com/mailcellar/mailcellar) keeps a local backup of Gmail and other mail, and can move old mail out of the mailbox and back again. [stat-arb-from-scratch](https://github.com/tcrossland/stat-arb-from-scratch) tests whether a mean-reversion signal in US stocks survives trading costs. So far it doesn't. [claude-code-methodology](https://github.com/tcrossland/claude-code-methodology) sets out a file-first way of working with Claude Code.

Older: [spacy-annotator](https://github.com/tcrossland/spacy-annotator), a 2017 web app for tagging named entities in text and training a spaCy model on them.
